# Privacy Policy

Last updated: May 21, 2026

## Overview

Screen Recorder is a Chrome extension with one clear purpose: recording the user's screen, a window, or the current tab locally from Chrome.

## Data Collection

Screen Recorder does not collect, sell, share, or transmit personal data.

The extension does not use analytics, advertising identifiers, tracking cookies, remote logging, or external data collection services.

## Screen, Tab, Audio, and Camera Access

Screen Recorder only accesses screen, tab, audio, or camera streams after the user explicitly starts a recording and grants the required Chrome permission.

Captured media is processed locally in the browser. Recordings are not uploaded to any server.

## Local Storage

The extension may store local preferences using Chrome local storage, such as:

- Selected source mode
- Output format
- Resolution
- Frame rate
- Microphone setting
- System audio setting
- Camera overlay setting

This information stays on the user's device and is used only to restore recording preferences.

## Data Sharing

Screen Recorder does not share user data with third parties.

## User Control

Users can stop a recording at any time, download the recording locally, clear extension data through Chrome settings, or uninstall the extension.
